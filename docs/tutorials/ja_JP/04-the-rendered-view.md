# レンダリング表示: Ctrl+T

`autodoc --gui` では、**Ctrl+T** でページを **そのまま表示** (書いたままの Markdown) と **レンダリング表示** (見出しはそれぞれの大きさで、記号は隠れ、表、コード、Mermaid 図が描画された状態) の間で切り替えます。

```mermaid
flowchart LR
  R["そのまま表示: Markdown"] -->|Ctrl+T| D["レンダリング表示: 読むときの姿"]
  D -->|Ctrl+T| R
```

レンダリング表示もエディターのままです。どの行も編集でき、カーソルのある行は Markdown を、それ以外の行は描画結果を表示します。もう一度 Ctrl+T を押すと、そのまま表示に戻ります。

**HTML ファイル** を開くときは、開き方を尋ねられます: **簡略化** (テキストを読み取り専用で表示) か、**そのまま** (HTML 自体を編集して保存) です。そのまま開いた HTML ファイルのレンダリング表示はそのページ自体で、ページ独自のスタイルシートや画像とともにネイティブに描画されます。`j k` でスクロールし、リンクからノートやファイル、ブラウザーを開けます。

**ファイル › HTML をプレビュー** (SPC H) で、ノートのページをエディターの横に開きます。入力に合わせてリアルタイムに更新されます。

**右クリックメニュー**: 元に戻す、やり直し、コピー、切り取り、貼り付け、図を表示、リンクへ移動、戻る、そして GUI ではズームもあります。キーボードからは **Shift+F10**、キーボードにあれば **Menu** キー、または **SPC .** で開けます。

ターミナルにはレンダリング表示がありません。ターミナルでは、ページは常にそのまま表示です。

詳しくは: [リファレンス 第 4 章: リッチな執筆、埋め込み、エクスポート](../../reference/04-rich-authoring-embeds-and-export.md)。
