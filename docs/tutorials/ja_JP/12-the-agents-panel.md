# エージェントパネル: ノートの隣で AI エージェントを使う

AutoDoc は AI エージェントのコマンドライン (Claude Code、Codex、OpenCode など) を専用のパネルで実行し、それぞれにワークスペースの情報を伝えます。

**初回起動時** には、AutoDoc がエージェントのセットアップを提案します: PATH 上の Claude Code、Codex、Grok、Antigravity を探し、**設定** を押すとプロファイルを保存してエージェントを起動し、何を手伝えるかをエージェント自身に説明させます。**システム › エージェントを設定…** で、このカードを再び表示できます。

**プロファイルを追加する。** **システム › エージェントプロファイル…** (SPC G) から **追加…** を選び、名前と、エージェントを起動するコマンド (`claude --model opus` や `codex` など) を入力します。コマンド中の `{root}` と `{workspace}` は、ワークスペースのフォルダーと名前に置き換えられます。最初のプロファイルが既定になります。別のものを既定にするには **既定にする** を使います。

**SPC g** でパネルを表示します (エージェントが動いていなければ、既定のエージェントを起動します)。もう一度押すと隠れます。隠れたエージェントも動き続けます。

```mermaid
flowchart LR
  P[プロファイル] -->|SPC g| A[タブの中のエージェント]
  A -->|autodoc --call| D[(ワークスペースのインデックス)]
```

**ワークスペースを把握しています。** エージェントは、AutoDoc がワークスペースごとに用意する専用フォルダーで起動します。AutoDoc はそこに `AGENTS.md` と `CLAUDE.md` を書き出します: ワークスペースの名前とルート、そしてそこへのアクセス方法です。エージェントのパス上の `autodoc` はあなたのものと同じなので、`autodoc --call workspace.list` などの動詞は、あなたが検索しているのと同じインデックスに届きます。

**タブ。** エージェントごとにタブがあり、そのコードネームが名前になります。**+** で別のプロファイルを起動するか、実行中のものに移動します。タブのメニュー (`≡`、またはタブを右クリック) には **移動**、**再起動**、**閉じる**、**プロファイル…**、**テーマとフォント…**、**最大化**、**隠す** があります。

**パネルの中では** Esc も含め、すべてのキーがエージェントに送られます。**Ctrl+T** でノーマルモードに切り替わり、履歴の中を移動できます (`h j k l`、`/`、`v`、`y`)。そこで Esc を押すとパネルが隠れます。

**ページを送る。** **SPC a** でエージェントカードを開きます: **b** でページを、**f** で選択範囲をエージェントに送ります。

GUI では、**オプション › フォントとズーム…** で、エージェントの文字サイズをウィンドウの文字サイズに対する割合 (50%〜150%) で設定します。パネルのメニュー (≡) の **文字サイズ › 小さく**、**大きく** で 10% ずつ変えられます。ターミナルパネルも同じサイズを使います。
