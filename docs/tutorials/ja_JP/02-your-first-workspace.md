# はじめてのワークスペース

**ワークスペース** とは、AutoDoc がインデックスを保持するノートのフォルダーです。これにより、ノートを検索したりリンクをたどったりできます。ファイルはディスク上のプレーンな Markdown のままで、AutoDoc がファイルを移動することはありません。

1. AutoDoc を起動します: `autodoc --ui` または `autodoc --gui`。
2. ワークスペースを追加します: **移動 › ワークスペースを管理…** (SPC W) を開き、**追加…** から短い名前とフォルダーを指定します。
3. AutoDoc はバックグラウンドでフォルダーのインデックスを作成します。完了するとステータスラインに表示されます。
4. **SPC o** でノートを開き、**Ctrl+N** で新規作成、**Ctrl+S** で保存します。

```mermaid
flowchart LR
  F[ノートのフォルダー] -->|追加| W[ワークスペース]
  W -->|インデックス作成| S[検索とリンク]
  W -->|SPC o| P[ページ上のノート]
```

次回からは、`autodoc --ui` で前回使ったワークスペースが開き、`autodoc --ui <name>` で名前を指定して開けます。

詳しくは: [リファレンス 第 2 章: クイックスタートとワークスペース](../../reference/02-quickstart-and-workspaces.md)。
