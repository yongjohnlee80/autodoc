# ウィンドウ: フォント、ズーム、ヘルプ

`autodoc --gui` では、ウィンドウは選んだフォントで描画されます。**オプション › フォントとズーム…** で設定します:

- **セルフォント**: ページ、パネル、メニューの描画に使う等幅フォントと、そのサイズ
- **本文フォント**: レンダリング表示と HTML プレビューのフォント
- **ズーム**: 100% から 200% まで、全体に適用されます。**Ctrl+=** と **Ctrl+-** で段階的に変更し、**Ctrl+0** でリセットします。右クリックメニューからも変更できます。

ターミナルでは、フォントとサイズはターミナル自体の設定で決まります。

**オプション › エディターの設定…** (SPC ,) で、それ以外を設定します: ページの幅、テーマ、折り返し、行番号、各パネルを開く位置、通知を表示する隅。

**ヘルプ**: **F1** で、すべてのキーとそれぞれに必要な条件を一覧表示します。**SPC h** で通知の履歴を表示します。このチュートリアルは **ヘルプ › チュートリアル…** から開けます。

詳しくは: [リファレンス 第 3 章: モーダルエディターとパネル](../../reference/03-modal-editor-and-panels.md)。
