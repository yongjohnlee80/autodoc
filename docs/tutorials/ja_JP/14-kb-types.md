# KB タイプ: ノート術から始めるワークスペース

新しいワークスペースは、空の状態からも、**KB タイプ** からも始められます。KB タイプとは、あるノート管理の方法に沿ったフォルダー、テンプレート、スキーマのひとそろいで、すぐに書き始められます。

**タイプを指定してワークスペースを追加する。** **移動 › ワークスペースを管理…** (SPC W) から **追加…** を選びます:

1. **ルート**: フォルダーです。フルパスを入力して **新規フォルダー** を押すと作成され、**参照…** で既存のフォルダーを選べます。
2. **KB タイプ**: ひとつ選びます。AutoDoc がそれを取得し、何かを書き込む前に、フォルダーとそれぞれの用途を表示します。
3. **保存**: ワークスペースが追加され、タイプのフォルダーとファイルがその中に作成されます。すでにあるファイルはそのまま残り、上書きされることはありません。

```mermaid
flowchart LR
  A[ワークスペースを追加] --> T[KB タイプを選ぶ]
  T --> S[フォルダーを確認]
  S -->|保存| W[すぐ書き始められるワークスペース]
```

**タイプの一覧。**

- **Zettelkasten**: 走り書きのノート、文献ノート、永久ノート、そしてそれらを結びつける構造ノート。
- **PARA**: Projects、Areas、Resources、Archives (プロジェクト、エリア、リソース、アーカイブ)。
- **Slip-box**: 書き留めるための受信箱、完成したノートを収めるスリップボックス、参考資料、プロジェクト。
- **AutoVim coding KB**: プロジェクトの決定事項と知識 (ADR、規約、プレイブック、レビューなど)。コードに取り組む人と AI エージェントのためのものです。
- **なし**: 既存のフォルダーやコードリポジトリを、そのまま使います。
- **カスタム URL…**: 任意の KB タイプの `https://` git リポジトリ。

各タイプにはテンプレートとフロントマタースキーマも含まれているので、新しいノートは正しい形で始まり、ページ上部の行にはノートに足りないものが表示されます。タイプは読み込まれてコピーされるだけで、その中の何かが実行されることはありません。

**既存のワークスペース** にもタイプを適用できます。Lua コマンドや `:lua` で `autodoc.run("kbtype.apply", "para.kb")` を実行すると、開いているワークスペースに PARA のフォルダーとファイルが追加されます。この場合も、すでにあるファイルはすべてそのまま残ります。
