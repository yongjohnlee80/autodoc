# 智能体面板：笔记旁的 AI 智能体

AutoDoc 在一个专用面板中运行 AI 智能体的命令行程序（Claude Code、Codex、OpenCode 等），并让每个智能体都了解你的工作区。

**首次运行时**，AutoDoc 会提议帮你设置一个：它会在你的 PATH 中查找 Claude Code、Codex、Grok 或 Antigravity，点 **设置** 即可保存配置、启动智能体，并让它介绍自己能为你做些什么。**系统 › 设置智能体…** 可以再次打开这张卡片。

**添加配置。** **系统 › 智能体配置…**（SPC G），然后点 **添加…**：填写名称和启动智能体的命令，例如 `claude --model opus` 或 `codex`。命令中的 `{root}` 和 `{workspace}` 会被替换为工作区的文件夹和名称。第一个配置就是默认配置；**设为默认** 可以改选另一个。

**它的环境变量。** 配置的 **环境变量** 字段以 `NAME=value` 的形式为智能体进程设置变量：`CLAUDE_CONFIG_DIR=~/.claude-work` 让 Claude Code 在另一个账号上运行，仍然是 Claude 智能体。`~` 和 `$HOME`（或 AutoDoc 的任何 `$VAR`）在智能体启动时展开，从不经过 shell。`AUTODOC_*` 变量属于 AutoDoc 自身，不能设置。配置以明文保存，所以不要放入机密信息。

**SPC g** 显示面板（如果没有正在运行的智能体，就启动默认的那个），再按一次则隐藏面板。隐藏的智能体会继续运行。

```mermaid
flowchart LR
  P[一个配置] -->|SPC g| A["智能体，在标签页中"]
  A -->|autodoc --call| D[(你的工作区索引)]
```

**它了解你的工作区。** 智能体在 AutoDoc 为该工作区准备的专用文件夹中启动，AutoDoc 会在那里写入 `AGENTS.md` 和 `CLAUDE.md`：内容是工作区的名称和根目录，以及如何访问它。智能体路径上的 `autodoc` 就是你的那个，所以 `autodoc --call workspace.list` 等动词访问的，正是你搜索的同一个索引。

**标签页。** 每个智能体有一个以其代号命名的标签页。**+** 启动另一个配置，或转到已在运行的那个。标签页菜单（`≡`，或在标签栏上右键）包含 **转到**、**重启**、**关闭**、**配置…**、**主题与字体…**、**最大化** 和 **隐藏**。

**在面板内**，所有按键都发送给智能体，包括 Esc。**Ctrl+T** 切换到 Normal 模式，以便在它的历史中移动（`h j k l`、`/`、`v`、`y`）；在 Normal 模式下按 Esc 会隐藏面板。

**把页面发给它。** **SPC a** 打开智能体卡片：**b** 把页面发送给智能体，**f** 发送所选内容。

在 GUI 中，**选项 › 字体与缩放…** 设置智能体的文字大小，以窗口文字大小的比例表示（50% 至 150%）；面板菜单（≡）中的 **文字大小 › 更小**、**更大** 每次调整 10%。终端面板也使用同一大小。
