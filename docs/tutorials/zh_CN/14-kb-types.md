# 知识库类型：自带方法的工作区

新工作区可以从空白开始，也可以从一个**知识库类型**开始：一种笔记方法所需的文件夹、模板和架构都已备好，只等你来填写。

**添加带类型的工作区。** **转到 › 管理工作区…**（SPC W），然后点 **添加…**：

1. **根目录**：工作区的文件夹。输入完整路径并按 **新建文件夹** 来创建它，或者用 **浏览…** 选择一个已有的文件夹。
2. **知识库类型**：选择一个。AutoDoc 会获取它，并在写入任何内容之前，先显示它的各个文件夹及各自的用途。
3. **保存**：工作区随即添加，类型的文件夹和文件也会在其中创建。已存在的文件会保留，绝不会被覆盖。

```mermaid
flowchart LR
  A[添加工作区] --> T[选择知识库类型]
  T --> S[查看它的文件夹]
  S -->|保存| W["一个工作区，只等填写"]
```

**有哪些类型。**

- **Zettelkasten**：闪念笔记、文献笔记和永久笔记，以及把它们串联起来的结构笔记。
- **PARA**：Projects（项目）、Areas（领域）、Resources（资源）和 Archives（归档）。
- **Slip-box**：用于收集的收件箱、存放成稿笔记的卡片盒，以及参考资料和项目。
- **AutoVim coding KB**：项目的决策与知识：ADR、约定、操作手册、评审等，供编写代码的人和 AI 智能体使用。
- **无**：现有的文件夹或代码仓库，保持原样。
- **自定义 URL…**：任意知识库类型的 `https://` git 仓库。

每种类型还带有模板和 frontmatter 架构，这样新笔记一开始就是正确的结构，页面上方的提示行也会指出笔记缺了什么。类型只会被读取和复制：其中的任何内容都不会运行。

**现有的工作区**也可以应用类型。在 Lua 命令或 `:lua` 中，`autodoc.run("kbtype.apply", "para.kb")` 会把 PARA 的文件夹和文件添加到当前打开的工作区，同样保留所有已有文件。
