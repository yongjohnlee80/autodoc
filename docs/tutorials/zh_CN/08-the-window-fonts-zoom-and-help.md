# 窗口：字体、缩放与帮助

在 `autodoc --gui` 下，窗口会用你选择的字体绘制。**选项 › 字体与缩放…**：

- **单元格字体**：页面、面板和菜单所用的等宽字体，以及它的字号；
- **正文字体**：用于渲染视图和 HTML 预览；
- **缩放**：100% 到 200%，作用于以上全部。**Ctrl+=** 和 **Ctrl+-** 逐级调整，**Ctrl+0** 恢复默认，右键菜单里也有缩放。

在终端中，字体和字号由终端自己的设置决定。

**选项 › 编辑器首选项…**（SPC ,）设置其余各项：页面宽度、主题、自动换行、行号、各面板从哪里打开，以及通知显示在哪个角落。

**帮助**：**F1** 列出所有按键及其各自的前提条件；**SPC h** 是通知历史；本教程位于 **帮助 › 教程…**。
