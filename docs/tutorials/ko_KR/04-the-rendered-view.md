# 렌더링 보기: Ctrl+T

`autodoc --gui`에서 **Ctrl+T**를 누르면 페이지가 작성한 그대로의 Markdown인 **원본** 보기와 **렌더링** 보기 사이를 오갑니다. 렌더링 보기에서는 제목이 크기에 맞게 표시되고, 기호는 숨겨지며, 표, 코드, Mermaid 다이어그램이 그려집니다.

```mermaid
flowchart LR
  R["원본, Markdown 그대로"] -->|Ctrl+T| D["렌더링, 읽히는 모습"]
  D -->|Ctrl+T| R
```

렌더링 보기도 여전히 편집기입니다. 모든 줄을 편집할 수 있습니다. 커서가 있는 줄은 Markdown을 보여 주고, 나머지 줄은 그 결과를 보여 줍니다. Ctrl+T를 다시 누르면 원본으로 돌아갑니다.

**HTML 파일**은 어떻게 열지 묻습니다. **간략**은 텍스트를 읽기 전용으로, **원본**은 HTML 자체를 편집하고 저장할 수 있게 엽니다. 원본 HTML 파일의 렌더링 보기는 그 페이지 자체로, 자체 스타일시트와 이미지를 써서 네이티브로 그려집니다. `j k`로 스크롤하고, 링크는 노트, 파일, 브라우저로 열립니다.

**파일 › HTML 미리 보기** (SPC H)는 노트의 페이지를 편집기 옆에 열고, 입력하는 대로 실시간으로 갱신합니다.

**오른쪽 클릭 메뉴**에는 실행 취소, 다시 실행, 복사, 잘라내기, 붙여넣기, 다이어그램 보기, 링크로 이동, 뒤로가 있고, GUI에서는 확대/축소도 있습니다. 키보드로는 **Shift+F10**, 키보드에 있다면 **Menu** 키, 또는 **SPC .**로 엽니다.

터미널에는 렌더링 보기가 없으므로 페이지는 원본으로 표시됩니다.
