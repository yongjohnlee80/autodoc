# KB 유형: 방법론으로 시작하는 워크스페이스

새 워크스페이스는 빈 상태로 시작하거나 **KB 유형**으로 시작할 수 있습니다. KB 유형은 노트를 관리하는 한 가지 방식의 폴더, 템플릿, 스키마로, 바로 채워 넣을 수 있게 준비되어 있습니다.

**KB 유형으로 워크스페이스 추가하기.** **이동 › 워크스페이스 관리…** (SPC W)에서 **추가…**를 누릅니다.

1. **루트**: 폴더입니다. 전체 경로를 입력하고 **새 폴더**를 눌러 만들거나, **찾아보기…**로 기존 폴더를 고릅니다.
2. **KB 유형**: 하나를 고릅니다. AutoDoc이 유형을 가져와, 무엇이든 쓰기 전에 폴더와 각 폴더의 용도를 보여 줍니다.
3. **저장**: 워크스페이스가 추가되고, 유형의 폴더와 파일이 그 안에 만들어집니다. 이미 있는 파일은 그대로 두며 절대 덮어쓰지 않습니다.

```mermaid
flowchart LR
  A[워크스페이스 추가] --> T[KB 유형 선택]
  T --> S[폴더 확인]
  S -->|저장| W["바로 채울 수 있는 워크스페이스"]
```

**유형 목록.**

- **Zettelkasten**: 임시 노트, 문헌 노트, 영구 노트, 그리고 이들을 묶는 구조 노트.
- **PARA**: Projects, Areas, Resources, Archives.
- **Slip-box**: 수집용 inbox, 완성된 노트의 slip-box, 참고 자료와 프로젝트.
- **AutoVim coding KB**: 프로젝트의 결정과 지식: ADR, 컨벤션, 플레이북, 리뷰 등. 코드를 다루는 사람과 AI 에이전트를 위한 유형입니다.
- **없음**: 기존 폴더나 코드 저장소를 있는 그대로.
- **사용자 지정 URL…**: 어떤 KB 유형이든 그 `https://` git 저장소.

각 유형에는 템플릿과 frontmatter 스키마도 들어 있어, 새 노트가 올바른 형태로 시작하고 페이지 위의 줄이 노트에 빠진 것을 알려 줍니다. 유형은 읽고 복사하기만 할 뿐, 그 안의 어떤 것도 실행되지 않습니다.

**기존 워크스페이스**에도 유형을 적용할 수 있습니다. Lua 명령이나 `:lua`에서 `autodoc.run("kbtype.apply", "para.kb")`를 실행하면 열린 워크스페이스에 PARA의 폴더와 파일이 추가되며, 이때도 이미 있는 파일은 모두 그대로 둡니다.
