# 첫 워크스페이스 만들기

**워크스페이스**는 AutoDoc이 색인을 관리하는 노트 폴더로, 덕분에 노트를 검색하고 링크를 따라갈 수 있습니다. 파일은 디스크에 평범한 Markdown 그대로 남으며, AutoDoc이 옮기는 일은 없습니다.

1. AutoDoc을 시작합니다: `autodoc --ui` 또는 `autodoc --gui`.
2. 워크스페이스를 추가합니다: **이동 › 워크스페이스 관리…** (SPC W)에서 **추가…**를 누르고, 짧은 이름과 폴더를 입력합니다.
3. AutoDoc이 백그라운드에서 폴더를 색인합니다. 끝나면 상태 줄에 표시됩니다.
4. **SPC o**로 노트를 열고, **Ctrl+N**으로 새 노트를 만들고, **Ctrl+S**로 저장합니다.

```mermaid
flowchart LR
  F[내 노트 폴더] -->|추가| W[워크스페이스]
  W -->|색인| S[검색과 링크]
  W -->|SPC o| P[페이지에 열린 노트]
```

다음부터는 `autodoc --ui`가 마지막으로 쓴 워크스페이스를 열고, `autodoc --ui <name>`은 이름으로 워크스페이스를 엽니다.
