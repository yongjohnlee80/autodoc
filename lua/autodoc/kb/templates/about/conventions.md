# conventions/

- **Holds:** binding rules: how to name, write, review, test, release. A convention is followed, not weighed.
- **Naming:** `<kebab-topic>.md`.
- **Type:** `convention`. `status`: draft, active or retired. Bump `revision:` when the rule changes.
- **Rules:** one topic per file. Search before adding one, and extend the existing file when the topic exists.
