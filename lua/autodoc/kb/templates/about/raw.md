# raw/

- **Holds:** source material: transcripts, specs, issues, exports. The user curates it.
- **Naming:** as the source came.
- **Type:** source files need no frontmatter.
- **Rules:** immutable. Agents read it and never edit, rename or delete anything in it. Summaries of raw material go in `reference/` (kind `source`).
